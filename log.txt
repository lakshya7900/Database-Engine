RECORD FORMAT
-------------
[id:int32][nameLength:uint32][name:N bytes][age:int32][score:int32]
Serialized size = 16 + name.length() bytes.

PAGE FORMAT
-----------
PAGE_SIZE = 4096 bytes.
Header = slotCount:uint16 + freeSpaceOffset:uint16 = 4 bytes.
Slot = recordOffset:uint16 + recordLength:uint16 = 4 bytes.
Records grow forward; slot directory grows backward.
Deleted slots use length=0; deletion compacts live bytes; slots are reused.

DISK FORMAT
-----------
Contiguous sequence of 4096-byte pages.
Physical page address = pageId * 4096.

TABLE / LOOKUP
--------------
Physical address = RID{pageId, slotId}.
Startup scans persisted pages and rebuilds unordered_map<int32_t, RID>.
Point lookup after startup: average O(1) hash lookup + one page read.
Full scan: O(number of stored records/pages).

OPERATIONS
----------
INSERT, SELECT by id, SELECT all/scan, UPDATE, DELETE, .stats.
